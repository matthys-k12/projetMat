# EmptyState
État vide ou d'erreur d'une liste — composant maison dans une `Card`.

- Icône Lucide 20px dans un carré 44px bordé (pas d'illustration), titre `heading-3`, phrase `muted` ≤ 360px, une action.
- Variante erreur : carré `danger-subtle` / icône `danger`, action « Réessayer », code d'erreur en `caption`.
- Recherche sans résultat : « Aucune demande ne correspond à « … » » + « Effacer la recherche ».
