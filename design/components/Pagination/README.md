# Pagination
Pagination de tableau — shadcn `<Pagination>`. Résumé à gauche (« 1–10 sur 58 demandes »), pages à droite.

- Page courante : bordure `border-input`, fond `surface`, `aria-current="page"`.
- Précédent / Suivant désactivés aux bornes. Au-delà de 7 pages, ellipse.
- En mobile : bouton « Charger plus » pleine largeur.
