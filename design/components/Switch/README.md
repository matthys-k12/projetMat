# Switch
Interrupteur actif/inactif — shadcn `<Switch>`, 36×20.

- Toujours accompagné d'un libellé texte (« Actif » / « Inactif ») : la position seule ne suffit pas.
- Activé : fond `primary` ; désactivé : fond `border-input`.
- Dans un tableau, `aria-label` avec le nom de la ligne (« Actif : Dell Latitude 5440 »). Toast de confirmation après bascule.
