# Alert
Message contextuel inline — shadcn `<Alert>`. Rayon `radius-sm`, texte `small`.

- Danger : fond `danger-subtle`, bordure `danger-border`, texte `danger-text`. Avertissement : équivalents `warning-*`.
- Un titre medium court + une phrase d'action. En tête de formulaire : résumé du nombre d'erreurs, les détails restent sous les champs.
