Emplacement de chargement — shadcn `<Skeleton>`, fond `subtle`, reflet discret désactivé avec `prefers-reduced-motion`.

- Reprend exactement la géométrie du contenu final (carte catalogue, ligne de tableau) pour éviter tout décalage.
- Conteneur : `aria-busy="true"` + libellé « Chargement du catalogue ».
