# AppHeader
Header de page 64px, fond `surface`, bordure basse — fil d'Ariane à gauche, cloche et menu du compte à droite.

- Fil d'Ariane `small` `muted`, séparateur `ChevronRight` 14px, dernier élément `text` medium avec `aria-current="page"`.
- Cloche : bouton icône avec `aria-label` incluant le nombre (« Notifications, 3 non lues ») et pastille `danger` 8px.
- Menu avatar : shadcn `<DropdownMenu>` (Profil, Déconnexion).
- Le titre H1 de la page est porté par le contenu, sous le header.
