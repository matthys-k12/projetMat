# Avatar
Initiales dans un cercle — shadcn `<Avatar>` + `<AvatarFallback>`. 28px (tableaux, header) ou 40px (fiche demandeur, commentaire).

- Fond `subtle`, texte `muted-strong` 11px semibold. Une seule couleur pour tous : pas de couleur générée par utilisateur.
- Toujours accompagné du nom en texte.
