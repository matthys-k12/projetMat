# Select
Liste de choix — shadcn `<Select>` (Radix). Même boîte que Input, chevron `ChevronDown` 16px `muted`.

- Sélecteur de matériel : afficher le stock à droite (« 3 en stock », en `warning-text` si stock faible) et désactiver les options à 0.
- Filtres de tableau : préfixe muet dans la valeur (« Statut : En attente ») quand aucun libellé n'est visible, avec `aria-label`.
- Plus de 10 options : utiliser `<Command>` (combobox avec recherche).
