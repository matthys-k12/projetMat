# SegmentedControl
Choix exclusif de 2 à 4 options courtes — shadcn `<Tabs>` / `<TabsList>` utilisé comme filtre, ou `<ToggleGroup type="single">`.

- Fond `subtle`, item actif en `surface` + `shadow-sm`, texte inactif `muted-strong`.
- Rôle `radiogroup` avec `aria-label` ; flèches gauche/droite pour naviguer.
- Pour plus de 4 options ou des compteurs, utiliser `Tabs` (souligné).
