# DropZone
Zone de dépôt d'image — composant maison (react-dropzone). Bordure pointillée `border-input`, fond `background`, rayon `radius-lg`.

- Activable au clavier (Entrée/Espace ouvre le sélecteur). Au survol de glisser : bordure `primary`, fond `primary-subtle`.
- Après dépôt : aperçu 4:3 + nom du fichier + bouton « Remplacer ». Erreur de format/poids sous la zone.
