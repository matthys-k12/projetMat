# Dialog
Fenêtre modale de saisie — shadcn `<Dialog>`. 480px, padding 24px, rayon `radius-lg`, voile `overlay`.

- Titre `heading-3`, description `muted`, champs, pied aligné à droite (Annuler outline, action primary ou destructive).
- Bouton de fermeture icône avec `aria-label="Fermer"` ; Échap ferme ; focus piégé et placé sur le premier champ.
- Usages : création/édition de catégorie, refus avec motif obligatoire.
