# ProductCard

- Ordre : catégorie (`caption` `muted`) · nom (`heading-3` 15px) · description tronquée à 2 lignes · badge de disponibilité + « N disponibles ».
- Sans photo produit : icône Lucide 56px trait 1.25 en `muted` (Laptop, Monitor, Mouse, Headphones, Cable, HardDrive).
- Grille 4 colonnes à 1440px, gouttière 16px ; liste en mobile.
