# AlertDialog
Confirmation d'une action irréversible — shadcn `<AlertDialog>`.

- Titre = question qui nomme l'objet (« Annuler la demande REQ-2026-000012 ? »), description = conséquence.
- Deux boutons aux libellés explicites : « Conserver la demande » (outline, focus par défaut) et « Annuler la demande » (destructive). Jamais « Oui / Non ».
